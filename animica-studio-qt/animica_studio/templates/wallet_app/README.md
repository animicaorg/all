# {{name}} — Wallet App (stub)

A minimal, **read-only** Animica wallet / payment stub generated by Animica
Studio Qt. It models an address (`anim1...` bech32m), a balance, and simulated
transaction history. It deliberately does **not** hold private keys, sign
transactions, or connect to any network — extend it from this safe baseline.

## Run

```bash
python wallet.py
```

Writes a `wallet_state.json` snapshot of the simulated wallet.

## Safety

- No private keys, seeds, or signing.
- No outbound network calls.
- Suitable as a learning / UI starting point only — never paste real seeds here.

For the real wallet, see [wallet.animica.org](https://wallet.animica.org).
