# {{name}} — Miner Dashboard

A small **static dashboard** that polls the Animica pool mining status endpoint
(`https://pool.animica.org/api/mining/status`) and renders live headline stats.
Generated by Animica Studio Qt.

## Run

Open `index.html` directly, or serve the folder (recommended, avoids CORS quirks):

```bash
python -m http.server 8080
```

Then visit http://localhost:8080

The dashboard refreshes every 15 seconds. Edit `STATUS_URL` in `app.js` to point
at a local pool instance if needed.
