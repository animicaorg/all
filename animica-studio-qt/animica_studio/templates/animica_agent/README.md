# {{name}}

A tiny **Animica inference agent** that calls an OpenAI-compatible
`/chat/completions` endpoint. Generated by Animica Studio Qt.

## Install

```bash
python -m pip install -r requirements.txt
```

## Configure

```bash
export ANIMICA_ENDPOINT="https://pool.animica.org/v1"   # or http://localhost:8000/v1
export ANIMICA_API_KEY="<optional-bearer-token>"
export ANIMICA_MODEL="anm-fast-8b"                       # or anm-pro-70b
```

## Run

```bash
python agent.py "Explain what Animica is in one sentence."
```

Works against the Animica pool, a local OpenAI-compatible server, or any
compatible endpoint (Ollama at `http://localhost:11434/v1`).
