# AICF VM-PY Contract Examples

These examples demonstrate the deterministic contract-to-AICF pattern:

1. Escrow/fund ANM budget in deterministic contract state
2. Emit AI job intent event (model call or agent task)
3. Off-chain AICF network executes job
4. Submit commitment/reference back to chain
5. Finalize payout/refund deterministically

Files:

- `summarize_document_contract.py`
- `classify_records_contract.py`
- `embeddings_contract.py`
- `agent_review_contract.py`
- `multi_step_research_agent_contract.py`
- `ai_escrow_pattern_contract.py`
- `agent_workflow_pattern_contract.py`
