Step 3 — send

A native anim1… recipient is bound automatically, then paid natively.

How it works. Each EVM address maps to a relayer-held native account. A deposit credits that account; an EVM-signed transaction moves it — to another EVM address, or (after a one-time bind) to a native anim1 wallet. It is a custodial gateway: the operator holds the native keys; the EVM key is the authorization, not self-custody.
