> Deep-dive material lives in the public monorepo: https://github.com/animicaorg/all

## 1) Prerequisites

- **Node.js** ≥ 18 (for Studio/website tooling)
- **Python** ≥ 3.10 (for the Python SDK & tools)
- **Rust** ≥ 1.75 (optional; for Rust SDK & native ZK helpers)
- **pnpm** or **npm**, and **pip** (or **uv**/**poetry**) installed

Check:

```bash
node -v && npm -v
python3 --version
rustc --version


⸻

2) Start a local devnet

# Install the CLI, then start a local node (Docker-backed)
pip install animica
animica node up
animica node status
# (Want every optional extra too? See "Choosing your install" below.)
# Keep this running in a terminal; it exposes HTTP RPC and WS endpoints locally.
# Don't want to run a node yet? Use the public mainnet RPC instead:
# https://rpc.animica.org/rpc (JSON-RPC, POST only)


⸻

3) Open Studio

The hosted web Studio is being rebuilt — a holding page is live at studio.animica.org
in the meantime. Use the Linux desktop build from /studio, or run the web app locally:
	•	Self-hosted (example):

# if you cloned the monorepo
pnpm -C studio-web install
pnpm -C studio-web dev
# visit http://localhost:4321



From Studio you can edit → simulate → deploy → verify contracts end-to-end.

⸻

4) Use the CLI & SDKs

Python (published on PyPI as `animica` — CLI + client libraries):

Choosing your install:

pip install animica
# The complete client. Everything to mine, run a node, use the wallet, deploy
# Python contracts, run `animica up` (the unified miner: PoW + useful-work +
# GPU train/serve + Studio functions), and use the Studio SDK. The native CPU
# miner (animica-fastpow) is included by default. This is what most people want.

pip install "animica[all]"
# Everything above PLUS every optional extra: Qt desktop-wallet QR codes,
# the full distributed Studio client (cloudpickle for closures + omni-sdk for
# on-chain ANM escrow), and all server/operator dependencies pinned. Use it if
# you want the kitchen sink or are running pool/API infrastructure.
# Quote the brackets ("animica[all]") so zsh/macOS does not glob them.

# Create a wallet and inspect it (keys stay local)
animica wallet create --label mywallet
animica wallet show mywallet

# Query the live chain over the public RPC (illustrative —
# run `animica --help` for the exact command surface)
animica chain head --rpc-url https://rpc.animica.org/rpc

Doc: https://github.com/animicaorg/all/tree/main/sdk

TypeScript and Rust SDKs live in the monorepo (illustrative; build from
source — see the sdk/ README for current install instructions):

6) Common env vars

If pointing UI/SDKs to your local devnet (for mainnet, use the public RPC
https://rpc.animica.org/rpc and chain ID 1):

export ANIMICA_RPC_URL="http://localhost:8545"   # or https://rpc.animica.org/rpc
export ANIMICA_CHAIN_ID="1337"                   # mainnet: 1
export ANIMICA_EXPLORER_URL="https://explorer.animica.org"

7) Troubleshooting
	•	Can’t connect to RPC? Verify the devnet process is running and ports are open.
	•	SDK type errors? Ensure Node ≥ 18 and a clean install (rm -rf node_modules && pnpm i).
	•	Studio build fails? Clear cache: rm -rf node_modules .astro .vite then reinstall.
