# USDAN Platform Docs

USDAN is a 1:1 USD-backed token stack on Animica with:

- VM-PY contracts (`contracts/packages/usdan_*`)
- Backend API (`services/usdan-api`)
- Web app (`apps/usdan-web`)
- Modern Treasury integration abstraction (`services/usdan-api/src/providers/treasury`)
