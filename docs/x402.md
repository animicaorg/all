# x402 agent payments for Animica

**Status: reviewed scaffold in `apps/x402-gateway/`. NOT deployed, not wired
into nginx/systemd, hard-gated behind `ANM_X402_ENABLED=1`.**

## Why

x402 (`github.com/x402-foundation/x402`, spec v2 in force since 2025-12-09)
is becoming the default way agentic HTTP clients pay for API calls: the
server answers `402` with machine-readable payment requirements, the client
pays inside a request header, a facilitator verifies and settles on-chain,
the server serves and returns a receipt header. Animica already sells
compute, inference and data over HTTP; x402 lets agents buy those per-call
without accounts, API keys or PayPal — and it is a concrete utility story
for ANM via wANM.

## What the scaffold does

`apps/x402-gateway/` (zero-dependency Node 20, house style of animica-pay):

* **`src/middleware.js`** — wraps any route handler; unpaid requests get a
  spec-shaped 402 offering **two lanes**: USDC on Base (via an external
  CDP-compatible facilitator, for reach and Bazaar/x402scan indexability)
  and **wANM** — the SPL token minted by the solana.animica.org bridge —
  via our own facilitator (for ANM utility and sovereignty). Speaks both the
  v2 header wire (`PAYMENT-REQUIRED`/`PAYMENT-SIGNATURE`/`PAYMENT-RESPONSE`)
  and the legacy v1 body/`X-PAYMENT` wire. Flow: verify → produce resource →
  settle → deliver; failed settlement withholds delivery.
* **`src/facilitator.js`** — self-facilitation server implementing the spec
  §7 contract (`/verify`, `/settle`, `/supported`) for the `exact` SVM
  scheme over plain Solana JSON-RPC: static transaction-layout verification
  (instruction whitelist, exactly one `TransferChecked`, cryptographic check
  of the payer's ed25519 signature, fee-payer isolation), RPC checks of
  destination ownership/mint and source funding, replay protection keyed on
  the message hash, and fee-payer signing + broadcast + confirmation on
  settle.
* **`src/demo-server.js`** — `/free/ping` plus `/paid/echo` at $0.005, run
  with `ANM_X402_ENABLED=1 node src/demo-server.js`.
* **`test/`** — 33 `node --test` tests, all offline (mocked Solana RPC,
  loopback HTTP): 402 spec shape, verify/settle happy path, concurrent
  duplicate-settlement race, and rejections (wrong amount, wrong mint,
  replay, tampering, unknown programs, sponsor outside the fee slot, kill
  switch).

Full env table, run instructions and the lane rationale:
[`apps/x402-gateway/README.md`](../apps/x402-gateway/README.md).

## Deliberately not decided here

1. **USDC lane facilitator**: Coinbase CDP
   (`api.cdp.coinbase.com/platform/v2/x402`, needs an account) vs PayAI vs
   staying testnet-only. Business decision.
2. **wANM provisioning**: real mint address (lives with the
   solana.animica.org bridge config), treasury wallet, and a funded sponsor
   key for fee-paying. Ops decision; no key material exists in this repo.
3. **Which Animica endpoints get paid tiers** (chain-stats, inference,
   media, deploy?). Product decision — the middleware is endpoint-agnostic.

Until all three are made and reviewed, this stays a scaffold.
