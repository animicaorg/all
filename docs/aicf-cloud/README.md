# AICF Cloud Docs

AICF is Animica's ANM-native decentralized AI compute cloud.

## Scope

- Developers spend ANM for API/model/job execution.
- Providers earn ANM by running workloads.
- VM-PY contracts coordinate escrow, rewards, staking, slashing, disputes, and governance.
- Browser wallet support enables direct contract-calling flows.
