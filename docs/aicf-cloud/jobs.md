# Jobs

Endpoint: `POST /jobs`

Supported classes:

- `chat_inference`
- `embedding_generation`
- `batch_inference`
- `fine_tuning_training`
- `evaluation`
- `retrieval_indexing`
- `agent_task`
- `custom_compute`

Each job supports hardware requirements, ANM max budget, timeout, verification mode, output mode, callback, and dispute window.
