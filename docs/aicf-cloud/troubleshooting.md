# Troubleshooting

## `Insufficient ANM project balance`
Fund project or reduce max budget.

## `API key missing scope`
Issue key with required scopes for model/job endpoints.

## Jobs stuck queued
Check scheduler service health and provider node eligibility/stake.

## Provider not receiving jobs
Verify node runtime capability and heartbeat freshness.

## Dispute not resolving
Check admin role token and dispute state in `/admin/disputes`.
