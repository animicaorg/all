# Funding Contract Jobs With ANM

From UI:

1. Connect Animica wallet.
2. Approve ANM allowance for escrow contract.
3. Create contract job with budget.
4. Submit funding/reserve transactions.

From contract/API:

- `AICFJobEscrow.fund_job`
- `AICFJobEscrow.reserve_budget`

All balances are ANM-native.
