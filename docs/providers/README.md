## Onboarding flow

1. Download worker bundle from `/downloads`.
2. Generate `provider.config.json` and set payout wallet.
3. Run benchmark mode and review hardware detection.
4. Start worker daemon and validate heartbeat.
5. Track jobs and rewards in provider dashboard.
