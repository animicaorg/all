Animica upgrade guide

animica 9.0.0 — current release

activates at block 50,000pip install -U animica

9.0.0 does two big things: it opens the GPU Studios on animica.dev (Video · Audio · Render Farm — real GPU work, processed by independent miners), and it turns service IOUs into real on-chain pay: from block 50,000, the network can settle what it owes GPU miners, dVPN relays and hosting providers directly from the block reward — capped at 50 ANM per block (one-sixth of the 300 ANM subsidy, always under 20% of the block), carved from the miner output, never minted on top.

Do I need to do anything?

Full node, pool, or balance-tracking exchange — yes, upgrade before block 50,000:

pip install -U animica        # ≥ 9.0.0
# then restart your node / pool services

From 50,000, blocks may contain settlement anchors (treasury-signed transactions that pay accrued service IOUs out of that block's reward). A node still on 8.x treats the anchor as a plain transfer and computes different balances — it silently diverges the moment the first anchor posts. 9.0.0 nodes apply it deterministically.

GPU miner / media miner — upgrade to earn from the new studios, and set your payout address:

pip install -U animica
ANIMICA_MEDIA_REWARD_ADDRESS=anim1<your address> animica up

Your box then serves video upscaling/interpolation/subtitles/background removal/ shorts, audio stems/mastering, and Blender Cycles render chunks — sized to what your GPU can actually run. IOUs you accrue become claimable on-chain payouts once settlement activates. No address set = IOUs keep accruing; add the address any time.

Wallet or hosted-service user — nothing to do. Balances, keys and addresses are untouched.

What exactly activates at 50,000?

The IOU-settlement fork (shipped gated in 8.0.1, realized in 9.0.0). A settlement anchor is an ordinary signed transfer from the foundation treasury whose data field carries an ANMSETL1 payout list. In any block at/after 50,000 that contains valid anchors, the listed providers are credited in that block, with the total carved out of the miner subsidy — capped at 50 ANM per block and halving on the same schedule as the subsidy, so settlement is never more than a sixth of a block and decays with emission. Blocks without anchors are byte-identical to 8.x behaviour, and only the treasury can post an anchor. Inspect the live state any time:

animica settle status

What's new in the studios

  • Video Studio — Real-ESRGAN upscaling to 4K, RIFE 60 fps interpolation, Whisper auto-subtitles (SRT + burned), background removal, automatic vertical shorts.
  • Audio Studio — HDemucs stem separation and vocal isolation, denoise + loudness enhance, reference-matched mastering to LUFS targets.
  • Render Farm — upload a packed .blend; frames render as parallel Cycles chunks across GPU miners (Blender 4.2.9, auto-fetched, scripts disabled), assembled to MP4 or a frames zip.

Everything runs through the public job queue: free, no API key, jobs wait honestly for a miner and go through eventually. Files travel as private uploads, are handed only to the processing miner, and are wiped on delivery or TTL.
