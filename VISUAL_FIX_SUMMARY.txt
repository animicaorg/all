PROBLEM (Before Fix):

│ Mining Command:                                                         │

│                                                                         │
│ Error:                                                                  │
│   ⚠ Block template unavailable (insufficient_peers)                    │
│   Status: connected: 0, handshaking: 1, required: 1                    │
│   Peer stuck at: tcp://82.66.161.84:41596 [handshaking]               │
│                                                                         │
│ Why stuck?                                                              │
│   • Peer connection timed out during handshake                         │
│   • purge_stale() method existed but was NEVER CALLED                  │
│   • Peer remained in registry indefinitely                             │
│   • Mining blocked waiting for "connected" peer                        │
└────────────────────────────────────────────────────────────────────────┘

ROOT CAUSE:
┌────────────────────────────────────────────────────────────────────────┐
│ PeerRegistry.purge_stale() method:                                     │
│   ✓ Exists in p2p/node/peer_registry.py                               │
│   ✓ Removes sessions that never completed handshake                    │
│   ✓ Has timeout: handshake_timeout_s = 3.0 seconds                    │
│   ✗ NEVER CALLED from P2P service                                      │
│                                                                         │
│ Result: Stuck peers accumulate and block operations                    │
└────────────────────────────────────────────────────────────────────────┘

SOLUTION:
┌────────────────────────────────────────────────────────────────────────┐
│ Added to _task_watchdog_loop() in p2p/node/p2p_service_legacy.py:     │
│                                                                         │
│   while self._running:                                                 │
│       await asyncio.sleep(5.0)  # Every 5 seconds                     │
│                                                                         │
│       # NEW: Purge stale handshaking peers                            │
│       purged = self._peer_registry.purge_stale()                      │
│       if purged:                                                       │
│           log.info(f"Purged {len(purged)} stale peers")               │
│                                                                         │
│ Timeline:                                                               │
│   T+0s:  Peer starts connecting (DIALING state)                       │
│   T+1s:  Connection times out / fails                                 │
│   T+3s:  handshake_timeout_s exceeded                                 │
│   T+5s:  Watchdog runs, calls purge_stale()                           │
│   T+5s:  ✓ Stuck peer removed from registry                           │
│   T+6s:  System can retry with other peers                            │
│   T+7s:  New peer connects successfully                               │
│   T+8s:  ✓ Mining proceeds (connected: 1, required: 1)               │
└────────────────────────────────────────────────────────────────────────┘
